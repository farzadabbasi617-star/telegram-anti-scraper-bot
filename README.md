# 🛡️ Telegram Anti-Scraper Bot (هق با کی - HaghBaKie)

**ربات مدیریت پیشرفته تلگرام با قابلیت‌های دفاع در برابر اسکرپ، اسکن اعضا، ادد ممبر، مانیتورینگ هوشمند و چندین ماژول کاربردی دیگر**

این ربات به صورت اختصاصی برای تست‌های امنیتی روی گروه‌های **کاملا متعلق به خودتان** طراحی شده است. هدف اصلی، آشنایی با مکانیزم‌های اسکرپ و دفاع در برابر ربات‌های خرابکار است.

---

## ⚠️ هشدار مهم قانونی و اخلاقی

**استفاده از این ابزار برای هدف‌گیری گروه‌ها یا کانال‌هایی که مالک آن نیستید، ممنوع و خلاف قوانین تلگرام و قوانین کشوری است.**

توسعه‌دهنده هیچ مسئولیتی در قبال استفاده نامناسب از این کد ندارد. این پروژه صرفا جنبه آموزشی و تست امنیتی دارد و شما با اجرای آن مسئولیت تمام اعمال خود را می‌پذیرید.

---

## 🚀 قابلیت‌های اصلی

### 🛡️ بخش دفاع پیشرفته
- **سیستم کپچا هوشمند:** برای هر عضو جدیدی که وارد گروه میشه به صورت خودکار کپچای ۴ رقمی میفرسته و اگه پاسخ نده مسدود میکنه
- **هانی‌پات نامرئی:** هر ۱۰ دقیقه پیام‌های کاملا نامرئی (با کاراکترهای zero-width) حاوی لینک‌های تله در گروه کاشته میشه که اعضای عادی هیچوقت نمیبینن ولی اسکرپرهای API خوان اون رو میخونند و کلیک میکنند و فورا بن میشن
- **امتیازدهی اسپمر:** بر اساس نام کاربری، سن اکانت، رفتار در گروه به هر کاربر امتیاز میده و افراد مشکوک رو محدود/بن میکنه
- **تشخیص ورود و خروج سریع:** اگه کاربری کمتر از ۴ دقیقه در گروه بمونه و خارج بشه فورا به عنوان اسکریپت شناسایی و مسدود میشه
- **فیلتر اکانت‌های تازه:** اکانت‌های کمتر از ۲۵ روزه اجازه ورود به گروه رو ندارن (قابل تنظیم)
- **لیست بن دائمی:** لیست افراد بن شده در دیتابیس ذخیره میشه و بعد از ری‌استارت ربات هم باقی میمونه

### 🎯 بخش حمله و اسکرپ اعضا
- **۵ استراتژی پیشرفته استخراج:**
  1. لیست مستقیم اعضا + صفحه‌بندی با الفبای فارسی/انگلیسی/اعداد
  2. اسکن کامل تاریخچه پیام‌ها
  3. پیام‌های ورود عضو جدید (members join events)
  4. گروه‌های مشترک با اعضا
  5. واکنش‌های پیام (ری‌اکشن‌ها)
- **حمله موازی چند اکانت:** با استفاده از چند اکانت ذخیره شده به صورت همزمان و تقسیم استراتژی‌ها بین آنها، سرعت استخراج چند برابر میشه
- **نوار پیشرفت زنده:** در طول عملیات هر ۲ ثانیه نوار پراگرس 🟩⬜ با درصد پیشرفت، تعداد پیدا شده، سرعت، زمان سپری شده و آخرین فرد پیدا شده آپدیت میشه
- **ذخیره تدریجی:** هر ۵ نفری که پیدا میشه فورا در دیتابیس ذخیره میشه و در صورت کرش/فلود داده‌ای از بین نمیره
- **دکمه توقف اضطراری:** در وسط عملیات میتونید دکمه توقف رو بزنید و همه چیز متوقف میشه
- **خروجی CSV:** در آخر کار فایل اکسترکت شده برای دانلود ارسال میشه

### ➕ بخش اضافه کردن اعضا (ادد ممبر)
- **محدودیت هوشمند ۵۰ نفر در هر اکانت:** برای جلوگیری از بن شدن اکانت‌ها سقف اضافه کردن به ۵۰ نفر در هر اکانت محدود شده
- **ادد موازی چند اکانت:** با چند اکانت به صورت همزمان ادد میکنه و ظرفیت خالی اکانت‌ها رو بهینه استفاده میکنه
- **داشبورد زنده:** تعداد ادد شده، ارورها، ظرفیت باقی‌مانده هر اکانت در زمان واقعی نمایش داده میشه
- **تاریخچه ادد:** لیست افرادی که قبلا اضافه شدن در دیتابیس نگه داشته میشه و از اضافه کردن تکراری جلوگیری میکنه

### ⏱️ اسکن خودکار پس‌زمینه
- در بازه‌های زمانی قابل تنظیم (۳۰/۶۰/۱۲۰/۲۴۰ دقیقه) به صورت خودکار شروع به اسکن اعضای گروه هدف میکنه
- تمام نتایج مستقیم به دیتابیس Neon ذخیره میشن
- هر بار بعد از اسکن گزارش کامل برای ادمین ارسال میکنه

### 🗄️ دیتابیس ابری Neon PostgreSQL
- **ماندگاری کامل داده‌ها:** تمام اطلاعات شامل لیست اعضا، سشن اکانت‌ها، تاریخچه ادد، تنظیمات، پروژه‌های ذخیره شده و لیست بن‌شده‌ها در دیتابیس ابری Neon ذخیره میشن
- **بکاپ باینری سشن:** بعد از هر بار استفاده از اکانت، فایل سشن به صورت BYTEA در Neon بکاپ گرفته میشه و در صورت پاک شدن دیسک رندر (ری‌استارت/دیپلوی جدید) به طور خودکار بازیابی میشه
- **دیگه هیچ داده‌ای با هر ری‌استارت از بین نمیره**

### 🔍 پروژه‌یاب اوپن‌سورس
- جستجو در گیت‌هاب، گیت‌لب و کدبرگ
- ۶ دسته‌بندی محبوب
- ترند روز گیت‌هاب
- جستجوی دلخواه
- علاقه‌مندی (ستاره کردن/بوکمارک)
- ردیاب آپدیت ۶ ساعته
- خروجی CSV

### 📥 دانلودر رسانه
- دانلود از تیک‌تاک، اینستاگرام، یوتوب شورت، توییتر/X، ردیت، آپارات، پینترست، ساوندکلاود، ویمئو
- با استفاده از API رسمی cobalt

### 💾 بکاپ و مانیتورینگ
- بکاپ کامل تمام دیتا به فرمت JSON
- پنل سلامت سیستم (استفاده CPU/RAM)
- سیستم کیپ الایو هر ۲۸۰ ثانیه برای جلوگیری از هایبرنیت شدن سرویس رایگان Render
- endpoint سلامتی `/`

## 🧱 معماری پروژه و ساختار فایل‌ها

| فایل | توضیح |
|-------|-------|
| `bot.py` | فایل اصلی بات، منوها، هندلر پیام/کالبک، مدیریت کلیه جریانات |
| `attacker.py` | کلاس `AdvancedScraper` - موتور اصلی اسکرپ با تمام استراتژی‌ها |
| `defender.py` | ماژول دفاع پیشرفته، کپچا، هانی‌پات، امتیازدهی اسپمر |
| `parallel.py` | موتور اجرای همزمان عملیات اسکرپ/ادد با چند اکانت |
| `bg_scraper.py` | اسکن خودکار پس‌زمینه |
| `db.py` | تمام توابع اتصال به دیتابیس Neon و کار با جدول‌ها |
| `project_finder.py` | ماژول جستجوی پروژه در گیت‌هاب/گیت‌لب/کدبرگ |
| `downloader.py` | دانلودر رسانه با cobalt |
| `hunter.py` | ماژول قدیمی شکارچی که با پروژه‌یاب جایگزین شده (فقط برای سازگاری باقی مونده) |
| `requirements.txt` | لایبرری‌های مورد نیاز |
| `runtime.txt` | نسخه پایتون برای رندر |
| `Procfile` | دستور استارت سرویس روی رندر |

### کلاس‌های اصلی:
- `AdvancedScraper`: هر اکانت کاربری که میخواهد اسکرپ/ادد کند از این کلاس ساخته می‌شود. ویژگی‌ها:
  - `force_fresh=True`: برای لاگین اولیه سشن کاملا مجزا و موقت استفاده میکند و بعد از موفقیت به صورت اتمیک به فایل دائمی منتقل میکند
  - Device Fingerprint ثابت برای هر اکانت (همیشه با همان مدل گوشی/ورژن اپ وصل میشه تا تلگرام متوجه نشه)
  - تابع `robust_connect` با تلاش مجدد خودکار در صورت قفل بودن دیتابیس SQLite
  - نوار پیشرفت داخلی و هارت‌بیت
  - پرچم `request_stop()` برای توقف اضطراری
- `AdvancedDefender`: مدیریت کلیه امور دفاعی در گروه

## 🚀 راه‌اندازی و دیپلوی

### پیش‌نیازها:
- توکن ربات بات‌فادر تلگرام
- آیدی عددی ادمین ربات
- اکانت تلگرام API ID و API Hash (پیشفرض روی 6/eb06d4abfb49dc3eeb1aeb98ae0f581e تنظیم شده - در صورت بن شدن از my.telegram.org دریافت کنید)
- دیتابیس رایگان Neon PostgreSQL
- اکانت رایگان Render

### متغیرهای محیطی:
```
BOT_TOKEN=توکن ربات شما از @BotFather
ADMIN_ID=آیدی عددی شما
API_ID=6
API_HASH=eb06d4abfb49dc3eeb1aeb98ae0f581e
DATABASE_URL=آدرس اتصال Neon PostgreSQL
```

### دیپلوی روی Render رایگان:
1. این ریپازیتوری را فورک کنید
2. در رندر یک Web Service جدید به گیت‌هاب متصل کنید
3. متغیرهای محیطی را وارد کنید
4. رندر به صورت خودکار دیپلوی میکند
5. سیستم کیپ الایو خود ربات هر ۲۸۰ ثانیه به خودش پینگ میزند و از خواب زمستانی رندر جلوگیری میکند

## 🔧 نکات مهم توسعه
- زبان: Python 3.11+ (روی رندر با 3.14 هم تست شده)
- کتابخانه اصلی: Pyrogram 2.0.106
- سشن‌ها در پوشه `saved_sessions/` ذخیره میشن
- هرگز فایل `antiscraper_bot.session` را پاک نکنید (سشن خود ربات است)
- قبل از هر اتصال جدید، حلقه `robust_connect` فایل‌های قفل را پاک میکند
- قفل سراسری `asyncio.Lock` از دسترسی همزمان به سشن‌ها جلوگیری میکند

## 🤖 دستورالعمل برای ایجنت‌های هوش مصنوعی بعدی:
> ⚠️ نکات مهم برای ادامه توسعه:
> 1. همیشه از `robust_connect()` برای اتصال Client ها استفاده کنید
> 2. برای لاگین اکانت جدید همیشه `force_fresh=True` بزنید
> 3. `device_fp` هر اکانت باید ثابت بماند
> 4. تمام هندلرها را در try/except بپیچید
> 5. پیام‌های پیشرفت باید دکمه `⏹️ توقف` با `callback_data="stop_op"` داشته باشند
> 6. هر ۵ نفر پیدا شده `incremental_save_cb` را صدا بزنید
> 7. از `_connect_lock` برای جلوگیری از database is locked استفاده کنید
> 8. کیپ‌الایو رو تغییر ندهید
> 9. `MAX_ADD_PER_ACCOUNT` را بالاتر از ۵۰ نبرید
